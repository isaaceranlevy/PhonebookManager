# Nimbus Phonebook — מדריך שימוש

Nimbus מאפשר לנהל ספר טלפונים משותף לטלפוני Yealink. הנתונים נשמרים במחשב המקומי, ללא שירות ענן.

## התחלה

1. טכנאי מעתיק את `phonebook.exe` לתיקייה קבועה ומתקין את השירות בחלון מנהל: `phonebook.exe install --subnet 192.168.1.0/24`. יש להחליף את תת־הרשת לזו שאושרה אצל הלקוח.
2. במחשב שבו הותקן השירות, פותחים בדפדפן `http://127.0.0.1:8765`.
3. לוחצים על **איש קשר חדש**, מזינים שם ומספר אחד עד שלושה ולוחצים **הוספה לספר**.
4. לוחצים על **שמירת שינויים**. הודעת הצלחה תוצג רק לאחר שהנתונים נשמרו בשרת.
5. דרך **חיבור הטלפונים** מעתיקים כתובת LAN לממשק Yealink, תחת Directory → Remote Phone Book.

הטלפון מרענן את הספר לפי התנהגות הדגם והקושחה; שינוי שמור אינו מבטיח רענון מיידי בכל מכשיר. יש לאמת תצוגת עברית וחיוג במכשיר לפני שימוש אצל לקוח.

## חיפוש ועריכה

אפשר לחפש לפי שם או חלק ממספר. כפתור העיפרון פותח עריכה; מחיקה דורשת אישור. גם עריכה ומחיקה מחייבות שמירת שינויים. לפני סגירה עם שינויים שלא נשמרו, הדפדפן מציג אזהרה. קיצור Ctrl+K מעביר לחיפוש.

## ייבוא וייצוא

CSV חייב להתחיל בשורה `name,phone1,phone2,phone3`. נתמכים UTF-8 ו־Windows-1255. בייבוא מוצגת תצוגה מקדימה לפני בחירה במיזוג או החלפה. כפילויות זהות מדולגות במיזוג. לאחר הייבוא עדיין צריך ללחוץ שמירת שינויים.

**Excel עלול למחוק אפסים מובילים בפתיחה ישירה. יש לייבא עמודות טלפון כטקסט.** ייצוא כולל BOM ותווי הגנה מפני נוסחאות; ייתכן שגרש מוביל יוצג בחלק מהתוכנות. הייבוא מסיר גרש הגנה יחיד. מספרי טלפון נשמרים כטקסט. אם יש שינויים שלא נשמרו, הייצוא כולל את הטיוטה הנוכחית; אחרת הוא כולל את הספר השמור.

## גיבויים

לפני שמירה של ספר קיים נוצרת גרסה לגיבוי. נשמרים עשרה גיבויים תקינים אחרונים. דרך **גיבויים ושחזור** בוחרים גרסה ומאשרים; השחזור נשמר מיד כגרסה חדשה. שינויים במסך שטרם נשמרו יוחלפו.

באנר אזהרה מציין שהספר נטען מגיבוי בגלל קובץ ראשי חסר או פגום. יש לבדוק את הרשימה ולשמור. אין למחוק קבצי נתונים כדי לפתור תקלה ללא גיבוי.

## גבולות גישה

הניהול נגיש רק במחשב המקומי, אך לכל המשתמשים בו, כולל משתמשי RDS. ספר ה־XML נגיש ללא סיסמה ברשת המורשית, ב־HTTP שאינו מוצפן. הלקוח נדרש לאשר מדיניות זו. אין לפתוח את פורט הניהול לרשת או להגדיר Port Forwarding מהאינטרנט.

## הסרה

טכנאי מפעיל `phonebook.exe uninstall` בחלון מנהל. השירות וחוק חומת האש מוסרים, והנתונים ב־ProgramData נשמרים. `--purge` מוחק במפורש גם נתונים בתיקיית ברירת המחדל בלבד, ללא אפשרות ביטול. קובץ ההפעלה עצמו אינו נמחק.
