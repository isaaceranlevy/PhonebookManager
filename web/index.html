חיבור הטלפונים

העתיקו כתובת רשת והזינו אותה בממשק הטלפון תחת Directory → Remote Phone Book.

  1. ודאו שהטלפון והמחשב נמצאים ברשת המורשית.
  2. הגדירו שם לספר והדביקו את הכתובת בטלפון.
  3. פתחו את הספר בטלפון ובדקו עברית ומספרי חיוג.
הגישה לספר ברשת היא ב־HTTP ללא הצפנה. יש לאשר זאת אצל הלקוח ולהגביל את חומת האש לתת־הרשת המורשית.

בשרת RDS כל משתמש במחשב יכול לגשת לממשק הניהול המקומי.
